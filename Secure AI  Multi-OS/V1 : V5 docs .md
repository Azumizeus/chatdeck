Comment fonctionne l’agent ?
Un seul agent, plusieurs casquettes : vous activez l’outil souhaité en cliquant sur son bouton dans la barre d’outils de l’agent (il s’illumine en bleu). L’agent adapte alors sa réponse en fonction de l’outil sélectionné.

Interaction naturelle : vous pouvez aussi taper une demande en langage clair dans la zone de texte (ex: "review le fichier app.js"). L’agent détectera automatiquement l’intention et utilisera l’outil approprié.

Réponses contextuelles : chaque action est accompagnée d’un message explicatif et d’une trace des outils exécutés (ex: "code-gen — Génération terminée").

Pourquoi un seul agent ?
Nous avons fait le choix d’un agent unique mais extrêmement complet pour :

Simplifier l’expérience : pas besoin de jongler entre plusieurs assistants.

Garantir la cohérence : l’agent a une vue d’ensemble de votre projet, ce qui évite les conflits entre outils.

Optimiser les performances : un seul moteur IA, léger et réactif, intégré nativement à l’environnement sécurisé.

Exemple d’utilisation
Activez l’outil Debug.

Tapez : "Corrige l’erreur dans la fonction validateInput".

L’agent analyse le code, détecte le problème et propose une correction dans l’éditeur, tout en affichant les modifications dans le panneau de discussion.

Bonus : l’agent est entièrement sécurisé
Il ne communique avec aucun serveur externe (tout est local dans votre navigateur).

Il respecte les règles du sandbox (chroot, réseau isolé, chiffrement AES‑256).

Ses actions sont limitées à l’environnement virtuel ; rien n’est persistant en dehors de la session.

En résumé : vous avez 1 agent avec 10 outils prêts à l’emploi, intégrés de façon transparente dans votre environnement de développement premium. Activez l’outil qui correspond à votre tâche, ou laissez l’agent deviner votre besoin à partir de vos requêtes. Il est là pour vous assister à chaque étape de votre projet.
